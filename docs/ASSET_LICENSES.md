## Reference projects

**Duke's Gambit** (0xMartin) is licensed CC BY-NC-SA 4.0: no commercial use, and adaptations must use the same license. It was studied for **architectural ideas only**: commit logic first then animate, an input lock during animation, AI thinking during animations, shader warm-up, server-side validation with animation grace time. **No code, scenes, models, sounds or tuned data were copied.** Its license is incompatible with MIT and with commercial distribution, so none of its material may be added.

## Rules for adding assets

1. Never download assets by bypassing login, payment or access restrictions.
2. Before committing, confirm that redistribution in a public repository and commercial use are both allowed.
3. Add a row to the shipped table with the author, URL, license and any required attribution, and add the credit to the in-game Credits text (`CREDITS_TEXT`).
4. The game must keep working without any optional or externally licensed asset.
